# One Word, First Thought

Entry for the make.fun bounty `u-0xkianno-one-word-first-thought-106abaf8` (Kiano Network, pot $5, top 7).

The entry is exactly one word: **syzygy** — the alignment of three celestial bodies in a straight line. Three y's, one vivid image, impossible to guess.

`main.py` (stdlib only) writes the word to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (fallback `/output`), validates it (exactly one word, 1–24 characters, not only whitespace), and verifies it by read-back.
